SWIR Flatfield Calibration

AirHARP2 SWIR sensor calibration · UMBC Earth and Space Institute · 2024–2025

Problem: Prepare SWIR sensor images for downstream Level 1A processing by characterizing response variation and correcting dark signal and pixel defects.

Contribution: Built modular Python tooling for dark-frame averaging and subtraction, composite generation across filter-wheel positions, quadratic-envelope flatfield characterization, outlier rejection, defect masking, and corrected-image generation.

Approach: Used cross-track and along-track profiles with ratio thresholding and Savitzky–Golay smoothing to support repeatable calibration runs and inspect fit quality.

Tools: Python, NumPy, SciPy, Pandas, Matplotlib, Pillow, and command-line batch workflows.

SWIR Level 1A Pipeline

AirHARP2 SWIR processing · UMBC Earth and Space Institute

Problem: Turn raw SWIR TIFF frames and associated metadata into consistently organized Level 1A products for analysis and archival.

Contribution: Implemented capture-ID matching between image and metadata records, chronological processing, flight-leg detection from timestamp gaps, and segmentation into standard five-minute NetCDF4 granules.

Output: Frame-based image data organized with timestamps, sensor state, and navigation records to support downstream inspection and analysis.

Tools: Python, NumPy, Pandas, NetCDF4, Pillow, multiprocessing, and XML parsing.

VNIR Quicklook Generator

AirHARP2 VNIR L1A data review

Problem: Make flight-campaign VNIR Level 1A data easier to review for coverage and data quality without manually inspecting each NetCDF4 granule.

Contribution: Built a modular Python command-line workflow that discovers VNIR L1A NetCDF4 files, reads their time coverage and sensor metadata, and creates quicklook plots for flight legs or requested time windows.

Output: PNG quicklooks combine pushbroom measurements at four fixed wavelengths with UTC time and cross-track pixel axes. An optional sensor-temperature panel adds instrument context to the same view.

Tools: Python, NetCDF4, NumPy, and Matplotlib.
